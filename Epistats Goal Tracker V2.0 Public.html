Backup and share

Everything here runs in your browser. Nothing is uploaded.

Browsers can clear saved site data without warning. Keep a backup somewhere you control, and make a fresh one after big changes.

Encrypted backup (AES-256-GCM)

Locks your data with a password before you copy or save it. Without the password nobody can read it, including you, so store the password safely.

Use a long passphrase you will remember.

If Save as file does nothing in your viewer, copy the text and paste it into a note or a file named backup.epistats.enc.

Anonymous progress summary

Counts and percentages only. Titles, notes and milestone names are left out, so you can share it safely.

Plain backup (not encrypted)

Readable JSON of all your goals and tasks. Anyone who gets this text can read everything in it.

Restore from a backup

Choose a backup file or paste its text. Encrypted backups need their password.

Erase data from this browser

Use this on a shared or public computer. It removes every goal and task saved here. Make a backup first if you want to keep them.
